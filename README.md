# ANANTA.NET Website

Perubahan pada halaman Area Layanan:
- Tombol overlay “Buka Kalibendo” di dalam peta dihapus agar peta tidak tertutup.
- Tautan untuk membuka lokasi di Google Maps tetap tersedia di bawah peta dan berubah sesuai wilayah yang dipilih.
- Chip Kalibendo, Bades, dan Gondoruso pada bagian hero diberi animasi mengambang halus dengan jeda bertahap.
- Animasi menghormati pengaturan prefers-reduced-motion.

Untuk deploy, unggah seluruh isi folder ke repository website dan tunggu deployment Cloudflare Pages selesai.
