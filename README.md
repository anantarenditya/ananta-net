# ANANTA.NET Website v33

Perbaikan katalog paket berdasarkan referensi CHAYO:
- Halaman Paket Internet memiliki hero ringkas bertema “Internet sesuai kebutuhan Anda” dengan poin layanan.
- Pratinjau paket di Home dan halaman Paket menggunakan carousel satu kartu pada satu waktu, kontrol panah, indikator titik, dan dukungan geser pada layar sentuh.
- Paket Normal 35 Mbps tetap diberi label Pilihan Populer.
- Kartu paket menampilkan kecepatan, harga, manfaat, perkiraan perangkat, biaya pemasangan, serta tombol Detail dan Berlangganan.
- Halaman Detail Paket dirancang ulang dengan kartu paket utama, fitur, ringkasan rekomendasi, catatan perangkat/performa, serta tautan ke paket lain.
- Harga sesuai brosur: Hemat 20 Mbps Rp115.000, Normal 35 Mbps Rp165.000, Premium 50 Mbps Rp225.000, Pro 100 Mbps Rp335.000.

Website statis HTML/CSS/JS. Untuk deploy: ganti file pada repository lokal `ananta-net`, lalu push ke branch `main` agar Cloudflare Pages memperbarui situs.
